🔒 One-Time Setup

Trust Iris on iPhone

Install the local certificate profile once to permanently stop Safari security warnings.

📥 Download Trust Profile 📄 Download Certificate (.crt)
1
Download the Profile
Tap Download Trust Profile above and tap Allow when Safari asks permission.
2
Install in Settings
Open iPhone Settings → Tap Profile Downloaded (near the top) → Tap Install in the top-right corner.
3
Enable Full Trust
Go to Settings → General → About → Certificate Trust Settings. Turn ON trust for Iris Camera Local CA.
