📷 Iris Webcam

Your iPhone as a High-Quality Windows Webcam — 100% in Safari

Open Source • MIT

The Challenge

  • Laptop webcams have poor low-light quality & low dynamic range.
  • Commercial apps demand App Store installs, accounts & paid tiers.
  • Cloud-relayed streams add 50–150ms latency and risk privacy.

The Iris Solution

  • Zero iPhone Installs: Runs directly inside native iOS Safari.
  • Zero Cloud Latency: 100% peer-to-peer over local home Wi-Fi.
  • Native Driver: Directly recognized in Zoom, Teams, Meet & OBS.
Technical Architecture & Features
Component Implementation Advantage
Web Client Vanilla WebRTC / WebKit in Safari No App Store download; works on any modern iPhone.
Local PKI & Trust On-device Root CA + .mobileconfig 100% offline, warning-free local HTTPS camera permissions.
Virtual Camera C++ Windows Media Foundation Driver Presents as a real hardware camera to Windows video apps.
Host Runtime Single-File .NET 8 Executable Portable, self-contained single .exe; runs from system tray.
Local Transport Direct Wi-Fi WebSockets / WebRTC Sub-30ms real-time response with zero cloud hops.
How It Works (3 Steps)
1
Run Iris on PC
Double-click Iris.exe. It sits quietly in the notification tray.
2
Open on iPhone
Open the local address in Safari and tap Start Camera.
3
Join Your Call
Select Iris Camera in Zoom, Teams, Meet or Discord.
